    Behind the map

    How the numbers were made

    • Boundaries come from the Census 2011 district map published by the DataMeet community.
    • Area and boundary length are measured on the WGS84 ellipsoid from the full-detail shapes. The shapes drawn here are simplified for the screen.
    • The map uses an Albers equal-area conic projection, so colour comparisons between districts are fair.
    • Neighbours and borders are found by comparing each district outline with the others, then checked by a separate program.

    Known limits

    • These are the Census 2011 boundaries. Rajasthan’s district map has changed since; the current layout is added in a later phase.
    • The source outlines overlap in a few places (largest: Alwar and Dausa, about 5.5 km²). This is reported here, not hidden.
    • Hindi and Urdu district names are drafts and have not yet been reviewed.

      What this build uses

      Geography
      Equal-area conic projection, choropleth classes, shape index, borders and adjacency
      Maths and statistics
      Geodesic area, quantile classes, ratios, and checks against a known total
      Programming
      Python (shapely, pyproj) for the data build, plain JavaScript and canvas for the map, automatic checks
      Languages
      English, Hindi and Urdu interface, including right-to-left layout
      AI-training habits
      Every result is checked independently and the known limits are written down
